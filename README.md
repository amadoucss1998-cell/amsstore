# LifeOS

Essential life skills for everyone — finance, health, cooking, legal rights, relationships, career, home & digital safety.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router v6
- Zustand (persisted progress & bookmarks)
- Lucide React icons

## Deploy

Connect to Vercel — `vite build` → `dist/`
